# E2-Algo — fiches de révision

Site GitHub Pages des fiches interactives E2-ALGO (HEIA-FR).

**URL :** https://philippe-ong.github.io/E2-Algo/

Le site est une page unique auto-contenue : les 10 fiches sont embarquées dans
`index.html`. Les PDF du cours ne sont pas publiés ; les numéros d'exercices
restent visibles dans les fiches.

La version par exercice est dans `exercices/` : 15 fiches avec l'énoncé,
la théorie nécessaire, une méthode et un mini-QCM.
