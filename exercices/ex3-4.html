Lotto : huit tirages sur liste doublement chaînée

Générer huit tirages de six numéros distincts dans une liste doublement chaînée triée, puis vider la liste après chaque tirage.

exercice 3.4 liste doublement chaînée · pNext/pPrev · put · doublons · rand/srand théorie : Listes chaînées
01
énoncé

Ce que demande l’exercice

Le programme simule huit tirages SwissLotto. Chaque tirage contient six numéros distincts choisis entre 1 et 42, plus un numéro chance entre 1 et 6.

La liste est doublement chaînée : chaque Element_t contient number, pNext et pPrev. Elle reste triée par ordre croissant.

a) implémenter showList ; b) dessiner l'insertion de 3 dans une liste contenant déjà 2 et 8 ; c) traiter les cas 1 (nouvelle tête) et 42 (nouvelle queue) ; d) implémenter put.

Le programme initialise srand(time(0)) une seule fois, génère les six numéros avec generateNumbers, affiche la liste et le numéro chance, puis appelle clearList.

02
théorie nécessaire

Les notions à mobiliser

Nœud double

Chaque Element_t contient number, pNext et pPrev. La liste est triée par ordre croissant ; le parcours avance tant que pCur->number < number.

Insertion triée

put cherche la position, puis relie le nouveau nœud à ses deux voisins : pNew->pPrev = pPrev, pNew->pNext = pCur, puis met à jour pPrev->pNext et pCur->pPrev.

Tête et queue

Si pPrev == NULL, le nouveau nœud devient la tête ; si pCur == NULL, il devient la queue. Les deux cas mettent à jour pNext/pPrev et la tête de liste.

Doublons et aléatoire

isAlreadyTaken rejette un numéro déjà présent. srand(time(0)) est appelé une seule fois ; rand() % 42 + 1 donne 1 à 42, rand() % 6 + 1 le numéro chance.

03
méthode

Comment procéder

  1. Créer la liste vide avec createSortedList.
  2. Initialiser le générateur une seule fois avec srand(time(0)).
  3. Pour chacun des 8 tirages, générer 6 numéros avec rand() % 42 + 1, en rejetant les doublons.
  4. Insérer chaque numéro avec put en mettant à jour pNext et pPrev ; traiter la tête et la queue.
  5. Afficher la liste triée et le numéro chance, puis vider la liste avec clearList.
04
application

Application à l’énoncé

exemple.cC11
typedef unsigned char LottoNbr_t;

typedef struct Element_s {
    LottoNbr_t        number;
    struct Element_s* pNext;
    struct Element_s* pPrev;
} Element_t;

static void generateNumbers(Element_t** ppList, unsigned int nbrOfNumbers)
{
    for (unsigned int i = 0; i < nbrOfNumbers; i++) {
        LottoNbr_t newNumber = 0;
        do {
            newNumber = (rand() % eTotalNbrOfLottoNumbers) + 1;
        } while (isAlreadyTaken(*ppList, newNumber));
        put(ppList, newNumber);
    }
}

void put(Element_t** ppHead, LottoNbr_t number)
{
    Element_t* pNew = malloc(sizeof *pNew);
    if (pNew == NULL) return;

    Element_t* pCur  = *ppHead;
    Element_t* pPrev = NULL;
    while (pCur != NULL && pCur->number < number) {
        pPrev = pCur;
        pCur  = pCur->pNext;
    }

    pNew->number = number;
    pNew->pPrev  = pPrev;
    pNew->pNext  = pCur;

    if (pPrev != NULL) pPrev->pNext = pNew;
    else               *ppHead      = pNew;
    if (pCur  != NULL) pCur->pPrev  = pNew;
}

Insertion de 3 entre 2 et 8 : pCur s'arrête sur 8, pPrev vaut 2 ; le nouveau nœud pointe vers 2 et 8, puis 2 et 8 pointent vers lui.

Insertion de 1 : pPrev == NULL, le nœud devient la tête. Insertion de 42 : pCur == NULL, le nœud devient la queue. Dans les deux cas, pPrev ou pNext vaut NULL du côté concerné.

Résultat. Huit tirages, six numéros triés et un numéro chance par ligne, sans doublon ; la liste doublement chaînée est vidée après chaque tirage.
05
erreurs fréquentes

Les pièges

À vérifier
  • Oublier de mettre à jour pPrev : le parcours arrière est faux.
  • Oublier le cas de la tête (pPrev == NULL) ou de la queue (pCur == NULL).
  • Appeler srand dans la boucle des tirages : la suite devient répétitive.
  • Oublier isAlreadyTaken ou clearList : doublons ou fuite mémoire.
