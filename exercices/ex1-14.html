énoncé

Ce que demande l’exercice

Donald a gagné à la loterie et invite sa famille proche. Les 15 membres partagent l'information avec une liste commune, selon la consigne phoneAlarm (diviser pour régner).

Consigne : si je n'ai rien à transmettre, je ne fais rien ; sinon je coupe ma liste en deux, j'appelle la première personne de chaque moitié et la charge de transmettre.

a) Dessiner l'organigramme récursif. b) Dessiner la séquence d'appel pour 15 entrées, puis pour 14.

c) Implémenter phoneAlarm avec l'extrait : ListRecord_t, cTheList, showCalledPerson.

02
théorie nécessaire

Les notions à mobiliser

Cas de base

size <= 1 : personne à prévenir, la fonction rend la main ; sans ce test, la récursion ne s'arrête jamais.

Deux moitiés du reste

list[0] est l'appelant, list[1..size-1] restent à prévenir : rest = size - 1, half1 = rest / 2, half2 = rest - half1. On appelle list[1] puis list[1 + half1]. La garde half1 > 0 évite d'appeler une personne inexistante.

Chaque personne une seule fois

Chaque appel prévient une personne : size − 1 appels. Pour 15 entrées, l'arbre complet (1 + 2 + 4 + 8) donne 14 appels et 3 niveaux ; pour 14 entrées, moitiés 6 + 7 et 13 appels.

Diviser pour régner

Chaque appel confie une liste deux fois plus petite : profondeur ≈ log2(size), 4 niveaux avec Donald, coût O(size).

03
méthode

Comment procéder

  1. L'appelant est list[0] : seuls list[1..size-1] restent à prévenir.
  2. Écrire le cas de base : size <= 1, return immédiat.
  3. Calculer rest = size − 1, half1 = rest / 2 et half2 = rest − half1.
  4. Appeler la première personne de chaque moitié non vide, puis lui confier cette moitié.
  5. Vérifier le total : size − 1 appels, chacun une seule fois.
04
application

Application à l’énoncé

exemple.cC11
#include "liste-telephonique.h"

/* Ex. 1.14 : list[0] = moi (déjà informé) ;
   list[1..size-1] = les personnes que je dois prévenir */
void phoneAlarm(ListRecord_t const list[], size_t size)
{
    if (size <= 1u) {          /* personne à prévenir : rien */
        return;
    }
    size_t const rest = size - 1u;     /* ma liste, sans moi */
    size_t const half1 = rest / 2u;    /* coupée en deux */
    size_t const half2 = rest - half1;
    if (half1 > 0u) {
        showCalledPerson(&list[1]);  /* 1re, moitié 1 ... */
        phoneAlarm(&list[1], half1); /* ... prévient sa moitié */
    }
    showCalledPerson(&list[1u + half1]); /* 1re, moitié 2 */
    phoneAlarm(&list[1u + half1], half2);
}

Pour 15 entrées, le reste vaut 14, coupé en 7 + 7 :

L'ordre est 2, 3, …, 15 : 14 appels, chacun une seule fois. Avec 14 entrées, le reste vaut 13, coupé en 6 + 7 : 1 appelle 2 puis 8, et la séquence va de 2 à 14, soit 13 appels.

Résultat. 15 entrées : 14 appels et 3 niveaux sous Donald ; 14 entrées : 13 appels, moitiés 6 + 7, personne n'est oublié.
05
erreurs fréquentes

Les pièges

À vérifier
  • Oublier half1 > 0 : avec un reste de 1, la même personne est appelée deux fois.
  • half2 = (size - half1 - 1) / 2 perd des personnes ; half2 = rest - half1.
  • 14 entrées donnent 13 appels, pas 14 : chaque appel prévient une personne.
  • Gyro, 877-764-2532-999, fait 16 caractères dans char[16] : pas de nul final, printf lit au-delà.
