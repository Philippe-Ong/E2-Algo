Convertisseur °C vers °F

Convertir une température de °C en °F avec une fonction, puis afficher la table de −20 °C à 30 °C.

01
énoncé

Ce que demande l’exercice

a) Afficher une ligne d'information sur le programme, puis une conversion, avec la formule T(°F) = T(°C) × 1,8 + 32.

b) Écrire une fonction qui reçoit une température en °C et retourne sa valeur en °F, puis ajouter son appel dans main.

c) Afficher la table des conversions de −20 °C à 30 °C par pas de 1 °C, en utilisant des constantes pour les bornes.

Le symbole ° peut s'écrire sur la console par le caractère de code 0xF8, soit 248.

02
théorie nécessaire

Les notions à mobiliser

Une fonction, une valeur

double celsiusToFahrenheit(double c) reçoit une copie de l'argument et retourne un double. Le prototype placé avant main suffit au compilateur ; le corps peut venir après.

Le facteur 1,8

1,8 s'écrit 1.8 en C et reste un littéral double : c * 1.8 + 32.0 calcule tout en virgule flottante. Avec des entiers, c * 9 / 5 + 32 tronque à chaque division.

Constantes et bornes

Deux constantes fixent la plage : enum { eMinC = -20, eMaxC = 30 };. La boucle va de eMinC à eMaxC inclus, soit 30 − (−20) + 1 = 51 tours.

Le symbole °

0xF8 = 248 est le ° de la page de code de la console Windows (CP850 ou CP437). En UTF-8, le même symbole n'a pas ce code : (char)0xF8 n'affiche ° que dans cette page de code.

03
méthode

Comment procéder

  1. Écrire la formule en double : c * 1.8 + 32.0.
  2. Isoler le calcul dans une fonction à un paramètre et à valeur de retour.
  3. Déclarer les bornes en constantes, puis boucler de −20 à 30 inclus.
  4. Afficher avec %+.1f pour garder le signe, et %c avec (char)0xF8 pour le degré.
  5. Vérifier quatre points de contrôle : −20, 0, 10 et 30.
04
application

Application à l’énoncé

exemple.cC11
#include <stdio.h>

enum { eMinC = -20, eMaxC = 30 };   /* les bornes, en constantes */

double celsiusToFahrenheit(double c)
{
    return c * 1.8 + 32.0;
}

int main(void)
{
    printf("%cC to %cF converter!\n", (char)0xF8, (char)0xF8);
    printf("Value of %5.2f%cC corresponds to %5.2f%cF\n",
           10.0, (char)0xF8, celsiusToFahrenheit(10.0), (char)0xF8);

    for (int c = eMinC; c <= eMaxC; c++)
    {
        printf("Value of %+5.1f%cC corresponds to %+5.1f%cF\n",
               (double)c, (char)0xF8, celsiusToFahrenheit(c), (char)0xF8);
    }
    return 0;
}

Résultat. 10,0 °C donne 50,0 °F ; −20 donne −4,0 ; −19 donne −2,2 ; 29 donne 84,2 ; 30 donne 86,0. La table compte 51 lignes.
05
erreurs fréquentes

Les pièges

À vérifier
  • Écrire c * 9 / 5 + 32 avec un int : 7 °C donne 44 au lieu de 44,6, la division tronque.
  • Taper 1,8 : la virgule est un opérateur en C, et l'expression 1,8 vaut 8.
  • Boucler jusqu'à 30 exclu : 50 lignes seulement, et la dernière valeur manque.
  • Attendre ° d'un printf en UTF-8 avec 0xF8 : ce code n'est celui du symbole que dans la page de code de la console.
