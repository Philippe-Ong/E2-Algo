02
théorie nécessaire

Les notions à mobiliser

Deux types, deux tailles

Address_t vaut 40 + 4 + 4 + 40 = 88 octets, Student_t 20 + 20 + 4 + 88 = 132. L'énumération occupe 4 octets. Le tableau de 30 places réserve 30 × 132 = 3 960 octets.

Le compteur voyage par adresse

Capacité (30) et nombre utilisé (count) sont distincts. addStudent reçoit size_t *pCount, copie par table[*pCount] = *pNew, puis incrémente (*pCount)++. Sans les parenthèses, on incrémente le pointeur.

Chaînes et strcmp

Une chaîne de 19 caractères au plus tient dans char[20] avec son caractère nul. strcmp compare les octets et rend négatif, nul ou positif ; == compare des adresses. « Émile » passe après « Zoé ».

Recherche et const

findByName parcourt et rend l'indice du premier nom égal, ou count si absent : au plus n comparaisons. Student_t const table[] et pS->lastName : const interdit d'écrire dans le carnet.

03
méthode

Comment procéder

  1. Compter : Address_t 88, Student_t 132, donc 30 × 132 = 3 960 octets.
  2. Déclarer Student_t studentsGE[30], size_t count = 0, puis memset.
  3. Écrire printStudents : message si count vaut 0, sinon parcours avec un pointeur const.
  4. Ajouter avec addStudent et &count : copie de la structure, puis (*pCount)++.
  5. Chercher avec findByName : strcmp sur lastName, retour de l'indice ou de count.
  6. Trier avec sortByLastName et vérifier Bykov, Lüthi, Sauber, Stallman, Torvalds, Wawrinka.
04
application

Application à l’énoncé

exemple.cC11
#include <stdbool.h>
#include <stddef.h>
#include <stdio.h>
#include <string.h>

enum { eNameLen = 20, eAddressLen = 40, eMaxStudents = 30 };
typedef char Name_t[eNameLen];
typedef char AddressName_t[eAddressLen];
typedef enum { eClass_E1a, eClass_E1bd, eClass_E2a,
    eClass_E2bd, eClass_E3_EL, eClass_E3_EN } Class_t;

typedef struct {
    AddressName_t street;
    int houseNbr;
    int zipCode;
    AddressName_t city;
} Address_t;

typedef struct {
    Name_t firstName;
    Name_t lastName;
    Class_t currentClass;
    Address_t homeAddress;          /* structure imbriquée */
} Student_t;

/* d) ajout par copie de la structure ; *pCount mis à jour */
bool addStudent(Student_t table[], size_t *pCount,
                Student_t const *pNew)
{
    if (*pCount >= eMaxStudents) {
        return false;               /* tableau plein */
    }
    table[*pCount] = *pNew;     /* copie de tous les champs */
    (*pCount)++;
    return true;
}

/* recherche linéaire : indice trouvé, ou count si absent */
size_t findByName(Student_t const table[], size_t count,
                  char const *name)
{
    for (size_t i = 0u; i < count; i++) {
        if (strcmp(table[i].lastName, name) == 0) {
            return i;
        }
    }
    return count;
}

/* g) tri à bulles sur le nom (strcmp < 0 : avant) */
void sortByLastName(Student_t table[], size_t count)
{
    bool swapped;
    do {
        swapped = false;
        for (size_t i = 1u; i < count; i++) {
            if (strcmp(table[i].lastName,
                       table[i - 1u].lastName) < 0) {
                Student_t const tmp = table[i];
                table[i] = table[i - 1u];
                table[i - 1u] = tmp;
                swapped = true;
            }
        }
    } while (swapped);
}

Six ajouts occupent les indices 0 à 5, soit 792 octets sur 3 960. Avant le tri, Linus Torvalds est en 0 et Richard Stallman en 1 ; après sortByLastName, l'ordre est celui de la sortie g) : Bykov, Lüthi, Sauber, Stallman, Torvalds, Wawrinka.

La recherche de « Stallman » rend 3 après le tri, count si le nom est absent.

Résultat. 6 étudiants ajoutés (792 octets sur 3 960) ; recherche linéaire en au plus 6 comparaisons ; après le tri : Bykov, Lüthi, Sauber, Stallman, Torvalds, Wawrinka.
05
erreurs fréquentes

Les pièges

À vérifier
  • *pCount++ avance le pointeur, pas le compteur ; écrire (*pCount)++.
  • == compare des adresses, pas des textes ; utiliser strcmp.
  • 20 caractères dans char[20] laissent zéro caractère nul ; 19 au maximum.
  • i <= count lit table[count], hors du tableau ; la borne est i < count.
