Rectangles, adresses et pointeurs de fonction

Décrire des rectangles, afficher coordonnées et adresses, calculer l'aire et trier par aire via un pointeur de fonction.

01
énoncé

Ce que demande l’exercice

L'application utilise structures, tableaux et pointeurs ; le tri à bulles de l'exercice 1.5 est réutilisé.

a) Définir un point (x/y) à 16 bits, puis un rectangle de quatre points et un membre pour la surface ; initialiser un tableau d'au moins trois rectangles.

b) Afficher les coordonnées avec une fonction qui reçoit un rectangle par pointeur, pour chaque élément.

c) Afficher aussi les adresses des coordonnées et en déduire la disposition mémoire.

d) Calculer la surface par une fonction à paramètre pointeur ; e) trier par surface avec bubblesort, appelé via un pointeur de fonction.

02
théorie nécessaire

Les notions à mobiliser

& donne l'adresse, * la suit

Rectangle_t *pRect = &table[0]; vise le rectangle. pRect->area est le raccourci de (*pRect).area : les parenthèses sont obligatoires, le point liant plus fort que l'étoile. Déréférencer NULL est un comportement indéfini.

Un tableau est contigu

p + 1 avance de sizeof(*p) : 4 octets pour un Point_t, 20 pour un Rectangle_t. Le coin k du rectangle r est à base + 20·r + 4·k ; area est à l'offset 16.

const, trois contrats

Rectangle_t const *pRect : le rectangle est en lecture seule, c'est le paramètre de printRectangle. const char *p : le texte ne change pas ; char *const p : l'adresse ne change pas.

Un pointeur de fonction choisit le tri

typedef void (*SortFunction_t)(Rectangle_t table[], size_t n); puis SortFunction_t sortFct = sortByArea; et sortFct(table, n). sortByArea et &sortByArea ont la même adresse.

03
méthode

Comment procéder

  1. Déclarer Point_t (deux int16_t) puis Rectangle_t (corners[4], area).
  2. Initialiser trois rectangles à la déclaration, dans l'ordre du tour des coins.
  3. Afficher avec printRectangle(Rectangle_t const *pRect), pour chaque indice.
  4. Afficher &pRect->corners[k] : 4 octets par coin, 20 par rectangle.
  5. Calculer l'aire avec computeArea : pC[2].x − pC[0].x, pC[2].y − pC[0].y.
  6. Trier par aire via sortFct(table, n), puis réafficher.
04
application

Application à l’énoncé

exemple.cC11
#include <stddef.h>
#include <stdint.h>
#include <stdio.h>

/* a) un point (16 bits), un rectangle */
enum { eNbrOfCorners = 4 };

typedef struct {
    int16_t x;
    int16_t y;
} Point_t;                            /* 2 x 2 octets */

typedef struct {
    Point_t corners[eNbrOfCorners];   /* ordre du tour */
    int32_t area;                     /* calculée en d) */
} Rectangle_t;

/* b) affichage : pointeur vers const (lecture seule) */
void printRectangle(Rectangle_t const *pRect)
{
    for (size_t k = 0u; k < eNbrOfCorners; k++) {
        printf("[%2d,%2d]", pRect->corners[k].x,
               pRect->corners[k].y);
    }
    printf("\n");
}

/* d) côtés parallèles aux axes : coins 0 et 2 opposés */
void computeArea(Rectangle_t *pRect)
{
    Point_t const *pC = pRect->corners;   /* = &corners[0] */
    int32_t const w = pC[2].x - pC[0].x;
    int32_t const h = pC[2].y - pC[0].y;
    pRect->area = (w < 0 ? -w : w) * (h < 0 ? -h : h);
}

/* e) tri à bulles par aire (structures copiées entières) */
void sortByArea(Rectangle_t table[], size_t n)
{
    size_t swaps;
    do {
        swaps = 0u;
        for (size_t i = 1u; i < n; i++) {
            if (table[i].area < table[i - 1u].area) {
                Rectangle_t const tmp = table[i];
                table[i] = table[i - 1u];
                table[i - 1u] = tmp;
                swaps++;
            }
        }
    } while (swaps != 0u);
}

typedef void (*SortFunction_t)(Rectangle_t table[], size_t n);

/* d) + e) : aires, puis tri via un pointeur de fonction */
void processRectangles(Rectangle_t table[], size_t n)
{
    SortFunction_t const sortFct = sortByArea;
    for (size_t i = 0u; i < n; i++) {
        computeArea(&table[i]);   /* adresse de l'élément i */
    }
    sortFct(table, n);        /* ou (*sortFct)(table, n) */
}

Chaque rectangle mesure 20 octets et chaque coin 4 : le coin 2 du rectangle 1 tombe à 0x61FECC + 20 + 8 = 0x61FEE8.

L'aire du rectangle 1, [0,0] [0,10] [10,10] [10,0], vaut 10 × 10 = 100. Les aires valent 100, 400 et 180 ; après tri : 100, 180, 400, avec les premiers coins [0,0], [0,5], [10,10].

Résultat. sizeof(Point_t) = 4, sizeof(Rectangle_t) = 20, trois rectangles = 60 octets contigus ; aire du rectangle 1 = 100 ; après le tri : [0,0], [0,5], [10,10].
05
erreurs fréquentes

Les pièges

À vérifier
  • Le point passe avant l'étoile : écrire (*pRect).area ou pRect->area.
  • p + 1 n'ajoute pas un octet mais sizeof(*p), soit 20 pour un Rectangle_t.
  • Trier area sans déplacer les coins ; échanger la structure entière.
  • f2(true) est un appel, pas une fonction : on affecte f2 ou &f2.
